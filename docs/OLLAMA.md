# راهنمای Ollama (اختیاری)

۱. Ollama را از ollama.com نصب کنید و یک مدل بگیرید، مثلاً: `ollama pull qwen2.5:7b` (برای فارسی مدل‌های بزرگ‌تر بهتر عمل می‌کنند؛ حافظه RAM کافی لازم است).
۲. در برنامه: **تنظیمات ← حالت هوش مصنوعی ← محلی (Ollama)**، آدرس `http://localhost:11434`، دکمه ↻ و انتخاب مدل، سپس «ذخیره».
۳. در این حالت هیچ متنی به اینترنت ارسال نمی‌شود.
